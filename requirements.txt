# Upper-bounded rather than exact-pinned (2026-08-05).
#
# Patch and minor releases still flow automatically, so these do NOT go stale —
# security and bug fixes arrive without intervention. What's gated is the MAJOR
# version bump, which is where APIs get removed and builds break, and which
# deserves a human choosing the moment.
#
# Before this, both were fully unpinned: CI installed whatever shipped most
# recently, unreviewed, on a repo whose workflow holds a write token. It also
# meant no reproducibility — on 2026-08-05 this laptop was on pandas 3.0.3
# while CI was on 3.0.5.
#
# To take a new major version: raise the ceiling here deliberately and run the
# build before merging. Dependabot alerts (repo Settings → Advanced Security)
# are the intended trigger for noticing a CVE in the meantime.
pandas>=3,<4
requests>=2,<3
