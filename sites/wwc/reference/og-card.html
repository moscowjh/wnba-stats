WWC social card — three variants

Each box below is exactly 1200×630, the Open Graph card size, followed by the same card at 40% — roughly how iMessage and Slack render it. Colors come from chrome.tokens_css(WWC.accent), flags and groups from wwc2026_teams.json, the date line from config.TOURNAMENT_STRAP; nothing here is hand-picked. No FIBA marks, flag emoji and text only.

Pick one, then rasterize it to sites/wwc/public/og.png at 1200×630. The emitter already gates on that file existing — drop it in and the next build emits the full card with no code change.
